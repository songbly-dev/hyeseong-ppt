05한 장의 형태

한 장 = 메시지 하나 + 그것을 보이는 그림 하나 + 못 박는 한 줄. 내용 규칙(설득 사이클·장수)은 스타일과 무관하게 SKILL.md 2절을 따릅니다.

왼쪽 · 말 .9fr

키커(선택) → h1 명사구, 핵심 명사에 Rausch 한 번 → 리드 한 문장(19px, muted).

본문 제목에 마침표·물음표를 찍지 않습니다.

오른쪽 · 증거 1.1fr

흐름 알약 / 2열 비교 / 숙소 카드 3장 / 단계 / 숫자 / 프롬프트 / 스크린샷 중 하나.

아래를 결론 밴드로 닫습니다. 프롬프트가 긴 장은 오른쪽을 넓힙니다.

06하지 않는 것

✕ 금지

  • 각진 면 (radius 0)
  • 한 장에 Rausch 면 두 개 이상
  • 본문 크기 글자에 Rausch 색
  • 두 겹·오프셋·색 그림자
  • 굵기 800 이상 (브랜드 워드마크만 예외)
  • 태그 나열 — 배지는 카드 하나에 하나
  • 아이보리·회색 배경, 순흑 #000
  • 장식용 이모지
  • 웹폰트 · CDN · 외부 이미지

✓ 대신 이렇게

  • 8 / 14 / 20px · 알약 · 원
  • 하나만 Rausch, 나머지는 잉크 #222
  • 작은 강조는 잉크 굵게
  • var(--lift) 한 단, 떠 있는 것에만
  • 700 까지 — 무게는 여백과 면으로
  • "고르는 쪽"·"NEW" 같은 표시에만 배지
  • 순백 #ffffff 바탕
  • 기능 기호만 → ↗ ✓ 01
  • 설치된 글꼴 · base64 인라인 이미지

07완료 전 체크

✓배경이 #ffffff 이고, 글자가 #222(순흑 아님)인가
✓Rausch 면이 한 장에 하나 이하인가
✓.accent 가 제목에만, 한 장에 한 번씩만 걸렸는가
✓후킹이 표지 한 장에만 있고, 본문 제목은 명사구인가
✓각진 면이 없고, 그림자가 var(--lift) 한 단뿐인가
✓굵기 800 이상이 브랜드 외에 없는가
✓표지 검색바에 빈 자리가 남지 않았는가
✓각 도해가 결론 밴드로 닫히는가 (밴드 6개 이하, Rausch 밴드 2개 이하)
✓외부 요청 0건인가
✓900px · 600px 로 줄여도 1단으로 접히는가
